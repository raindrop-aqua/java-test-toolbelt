    パターン

    書式と操作
    • [テーブル] の次の行に {列1|列2}、その後に値の行。
    • <null> は NULL。何も書かなければ空文字。
    • 列名の記号（検証のとき）：@ 比較しない、< <= > >= 大小、!= 等しくない、% 前方一致。投入では無視される。
    • 「パターン列」を有効にすると、各行の先頭がパターン番号（1,2 や gold,silver）になる。空なら全パターン共通。名前の大文字と小文字は区別せず、01・+1・全角の １ は 1 と同じパターン。
    • // で始まる行はコメント。
    • Enter / ↓ 下の行へ（最後の行では行を追加）、Shift+Enter / ↑ 上の行へ
    • Alt+N 値を <null> にする / 戻す
    • Excel などからコピーした表（タブ区切り）は、セルに貼り付けると複数のセルに展開される。列名の欄に貼ると列名になる。
    • 行と列の操作ボタン（移動・追加・複製・コメント化・削除）は、ツールバーの「行・列の操作」で表示・非表示を切り替えられる。
    • ファイルはこの画面にドラッグ＆ドロップしても開ける。
    • Chrome / Edge では、開いたファイルにそのまま上書き保存できる。他のブラウザではダウンロードになる。
