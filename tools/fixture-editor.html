    パターン

    書式と操作
    • [テーブル] の次の行に {列1|列2}、その後に値の行。
    • <null> は NULL。何も書かなければ空文字。
    • 列名の記号（検証のとき）：@ 比較しない、< <= > >= 大小、!= 等しくない、% 前方一致。投入では無視される。
    • 「パターン列」を有効にすると、各行の先頭がパターン番号（1,2 や gold,silver）になる。空なら全パターン共通。名前の大文字と小文字は区別せず、01・+1・全角の １ は 1 と同じパターン。
    • // で始まる行はコメント。
    • Enter / ↓ 下の行へ（最後の行では行を追加）、Shift+Enter / ↑ 上の行へ
    • Alt+N 値を <null> にする / 戻す
    • Excel などからコピーした表（タブ区切り）は、セルに貼り付けると複数のセルに展開される。列名の欄に貼ると列名になる。
    • 行と列の操作ボタン（移動・追加・複製・コメント化・削除）は、ツールバーの「行・列の操作」で表示・非表示を切り替えられる。
    • 「スキーマ」タブで DDL（CREATE TABLE の .sql ファイル、または貼り付け）を登録すると、入力しているテーブルの列の一覧を表示する（✓ ファイルにある、⚠ 必須なのに無い、· 無い、▶ 今の列）。列をクリックすると表のその列へ移動する。登録した DDL はブラウザに保存され、「↻」で読み直す。
    • DDL を登録すると、テーブル名を入力したときにテーブルの候補が出る（↑ ↓ と Enter で選ぶ）。列がまだ無ければ、全列・必須の列だけ・主キーだけを展開できる。列名を入力すると、まだ書いていない列が型とともに候補に出る。
    • DDL を登録すると、列名の下に型を表示する（ツールバーの「型」で切り替え）。スキーマに無い名前と、ファイルに無い必須の列は警告になる（必須の列の警告は、検証用のファイルなら問題ない）。
    • 「テーブル」タブ（右端のアイコン）には、ファイル内のテーブルが順に並ぶ。クリックするとそのテーブルへ移動する。
    • このパネルは右端の › ボタン（または表示中のタブのアイコン）で閉じられる。画面の幅が狭いときは表の上に重なり、Esc か表を触ると閉じる。
    • ファイルはこの画面にドラッグ＆ドロップしても開ける。
    • Chrome / Edge では、開いたファイルにそのまま上書き保存できる。他のブラウザではダウンロードになる。
